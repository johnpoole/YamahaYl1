### Voltage note
All three models (YL-1/YL-1E, HS-1/HS-1B, LS2) are listed as 12V in the spec table on p.11. The commonly stated 6V assumption may apply only to the earliest production (pre-1967) Japanese-market YL-1. Verify by reading the battery itself or checking open-circuit voltage (~12.6V = 12V system; ~6.3V = 6V system).
